# ADR-0003 — Lock Qt/OpenCV version and source provenance

Qt6 6.11.2; Qt Quick Controls and QML (no Qt Widgets UI); C++20. Linux Pe Qt SDK parts 03/04/05 were materialized from `/工具开发` and checked for CMake version and real offscreen five-process startup. Linux OpenCV 5.0.0 library bundle was materialized from the same source but M00 does **not** yet link/process images with it. OpenVINO 2025.4.1 is a future adapter. Windows Qt SDK bundle is not yet reconstructed/compiled and remains NOT_VERIFIED. Never use the older misleading reference note suggesting Windows OpenCV4.14 for this product.
